# Portfolio Implementation Plan for Ilyes Saddi

## Structure
- `index.html` — Main HTML file
- `style.css` — Global styles, design tokens, animations
- `main.js` — Interactivity, animations, scroll effects

## Sections
1. **Hero** — Name, title, animated tagline, social links (LinkedIn, GitHub, email)
2. **About** — Summary paragraph, key stats
3. **Education** — Timeline cards
4. **Experience** — Timeline with company, role, bullets
5. **Projects** — Card grid with tags/tech stack
6. **Skills** — Animated skill bars / pill tags by category
7. **Awards & Organisations** — Minimal cards
8. **Contact** — Email + social

## Design
- Dark mode with purple/cyan gradient accents
- Glassmorphism cards
- Smooth scroll + intersection observer animations
- Sticky navbar with blur
- Custom cursor (optional)
- Google Fonts: "Inter" + "Space Grotesk"
